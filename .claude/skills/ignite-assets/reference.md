# Ignite Assets Reference

Complete documentation for managing static assets in Ignite apps.

---

## Directory Structure

```
assets/
├── fonts/                    # Custom font files (.ttf, .otf)
│   └── CalSans-Regular.ttf
├── icons/                    # Icon images for Icon component
│   ├── back.png
│   ├── back@2x.png
│   ├── back@3x.png
│   └── demo/                 # Demo-specific icons (can be removed)
│       └── ...
└── images/                   # General images
    ├── logo.png
    ├── logo@2x.png
    ├── logo@3x.png
    ├── app-icon-*.png        # Generated app icons
    └── demo/                 # Demo-specific images (can be removed)
        └── ...
```

---

## Path Alias

The `@assets/` alias is configured in `tsconfig.json`:

```json
{
  "compilerOptions": {
    "paths": {
      "@assets/*": ["./assets/*"]
    }
  }
}
```

**Always use the alias:**
```typescript
// Good
require("@assets/icons/myIcon.png")

// Bad - avoid relative paths
require("../../../assets/icons/myIcon.png")
```

## Icons

### Icon Registry

Icons must be registered in `app/components/Icon.tsx` before use:

```typescript
export const iconRegistry = {
  back: require("@assets/icons/back.png"),
  bell: require("@assets/icons/bell.png"),
  caretLeft: require("@assets/icons/caretLeft.png"),
  caretRight: require("@assets/icons/caretRight.png"),
  check: require("@assets/icons/check.png"),
  hidden: require("@assets/icons/hidden.png"),
  lock: require("@assets/icons/lock.png"),
  menu: require("@assets/icons/menu.png"),
  more: require("@assets/icons/more.png"),
  settings: require("@assets/icons/settings.png"),
  view: require("@assets/icons/view.png"),
  x: require("@assets/icons/x.png"),
  // Demo icons (can be removed)
  clap: require("@assets/icons/demo/clap.png"),
  community: require("@assets/icons/demo/community.png"),
  // ...
}
```

### IconTypes

The `IconTypes` type is automatically derived from the registry:

```typescript
export type IconTypes = keyof typeof iconRegistry
// Results in: "back" | "bell" | "check" | ...
```

### Adding a New Icon

1. **Create icon files** with all density variants:

```
assets/icons/
  pizza.png       # Base size (e.g., 24x24)
  pizza@2x.png    # 2x (e.g., 48x48)
  pizza@3x.png    # 3x (e.g., 72x72)
```

2. **Register in iconRegistry**:

```typescript
export const iconRegistry = {
  // ...existing icons
  pizza: require("@assets/icons/pizza.png"),
}
```

3. **Use the Icon component**:

```typescript
import { Icon, PressableIcon } from "@/components"

// Static icon
<Icon icon="pizza" size={24} color={colors.tint} />

// Pressable icon
<PressableIcon
  icon="pizza"
  size={24}
  onPress={() => console.log("pressed")}
/>
```

### Icon Component Props

```typescript
interface IconProps {
  icon: IconTypes              // Required - registered icon name
  color?: string               // Tint color (defaults to theme.colors.text)
  size?: number                // Width and height
  style?: StyleProp<ImageStyle>        // Image style overrides
  containerStyle?: StyleProp<ViewStyle> // Container style overrides
}
```

### Icon Best Practices

1. **Use PNG format** - Best compatibility and transparency support
2. **Provide all densities** - `@2x` and `@3x` for crisp display
3. **Keep icons simple** - Single color, designed for tinting
4. **Consistent sizing** - Base size of 24x24 or 32x32 works well
5. **Use semantic names** - `chevronRight` not `arrow1`

## Images

### Using Images Directly

Images don't need registration - import directly:

```typescript
import { Image } from "react-native"

// Require the image
const welcomeImage = require("@assets/images/welcome-face.png")

// Use in component
<Image source={welcomeImage} style={{ width: 200, height: 200 }} />
```

### Image Density Variants

React Native automatically selects the correct density:

```
assets/images/
  hero.png        # @1x - used on low-density screens
  hero@2x.png     # @2x - used on medium-density screens
  hero@3x.png     # @3x - used on high-density screens
```

Only reference the base name:
```typescript
require("@assets/images/hero.png")  // RN picks correct variant
```

### App Icon Files

Generated by Ignite CLI, stored in `assets/images/`:

| File | Purpose |
|------|---------|
| `app-icon-all.png` | Source image for generation |
| `app-icon-ios.png` | iOS app icon |
| `app-icon-android-legacy.png` | Android legacy icon |
| `app-icon-android-adaptive-foreground.png` | Android adaptive foreground |
| `app-icon-android-adaptive-background.png` | Android adaptive background |
| `app-icon-web-favicon.png` | Web favicon |

### Generating App Icons

```bash
# From a 1024x1024 source image
npx ignite-cli generate app-icon ./my-icon-source.png

# Options
npx ignite-cli generate app-icon ./icon.png --skip-android
npx ignite-cli generate app-icon ./icon.png --skip-ios
```

### Generating Splash Screen

```bash
# From a source image
npx ignite-cli generate splash-screen ./my-splash.png

# With background color
npx ignite-cli generate splash-screen ./splash.png --background-color "#FFFFFF"
```

## Fonts

### Font Configuration

Fonts are configured in `app/theme/typography.ts`:

```typescript
import {
  Inter_300Light as interLight,
  Inter_400Regular as interRegular,
  Inter_500Medium as interMedium,
  Inter_600SemiBold as interSemiBold,
  Inter_700Bold as interBold,
} from "@expo-google-fonts/inter"

/**
 * Fonts to load via expo-font.
 * Google Fonts are imported, local fonts use require().
 */
export const customFontsToLoad = {
  // Google Fonts (via @expo-google-fonts packages)
  interLight,
  interRegular,
  interMedium,
  interSemiBold,
  interBold,
  // Local fonts (from assets/fonts/)
  "CalSans-Regular": require("@assets/fonts/CalSans-Regular.ttf"),
}
```

### Font Family Definitions

```typescript
const fonts = {
  calSans: {
    normal: "CalSans-Regular",
  },
  inter: {
    light: "interLight",
    normal: "interRegular",
    medium: "interMedium",
    semiBold: "interSemiBold",
    bold: "interBold",
  },
  // Platform-specific system fonts
  helveticaNeue: {
    thin: "HelveticaNeue-Thin",
    light: "HelveticaNeue-Light",
    normal: "Helvetica Neue",
    medium: "HelveticaNeue-Medium",
  },
  // ...
}

export const typography = {
  fonts,
  primary: fonts.inter,      // Body text
  display: fonts.calSans,    // Headlines
  code: Platform.select({ ios: fonts.courier, android: fonts.monospace }),
}
```

### Adding a Custom Local Font

1. **Add font file** to `assets/fonts/`:

```
assets/fonts/
  MyCustomFont-Regular.ttf
  MyCustomFont-Bold.ttf
```

2. **Register in customFontsToLoad**:

```typescript
export const customFontsToLoad = {
  // ...existing fonts
  "MyCustomFont-Regular": require("@assets/fonts/MyCustomFont-Regular.ttf"),
  "MyCustomFont-Bold": require("@assets/fonts/MyCustomFont-Bold.ttf"),
}
```

3. **Add font family definition**:

```typescript
const fonts = {
  // ...existing fonts
  myCustomFont: {
    normal: "MyCustomFont-Regular",
    bold: "MyCustomFont-Bold",
  },
}
```

4. **Use in styles**:

```typescript
import { typography } from "@/theme"

const $title: TextStyle = {
  fontFamily: typography.fonts.myCustomFont.bold,
  fontSize: 24,
}
```

### Adding Google Fonts

1. **Install the font package**:

```bash
pnpm add @expo-google-fonts/roboto
```

2. **Import and register**:

```typescript
import {
  Roboto_400Regular as robotoRegular,
  Roboto_700Bold as robotoBold,
} from "@expo-google-fonts/roboto"

export const customFontsToLoad = {
  // ...existing fonts
  robotoRegular,
  robotoBold,
}
```

3. **Add font family definition** and use as shown above.

## Cleaning Up Demo Assets

The boilerplate includes demo assets that can be removed:

```bash
# Remove demo icons
rm -rf assets/icons/demo/

# Remove demo images
rm -rf assets/images/demo/
```

Then update `iconRegistry` to remove demo icon references.

## Best Practices

1. **Organize by type** - Keep icons, images, and fonts in separate directories

2. **Always provide density variants** - `@2x` and `@3x` for sharp display

3. **Use path aliases** - `@assets/` for clean, maintainable imports

4. **Register icons** - Don't use `<Image>` for icons; use the `<Icon>` component

5. **Lazy load large images** - Use `require()` at component level, not module level

6. **Optimize images** - Compress PNGs and use appropriate dimensions

7. **Use semantic naming** - `userAvatar` not `img1`

8. **Clean up unused assets** - Remove demo assets before production

9. **Consider SVG icons** - For complex icons, consider `react-native-svg`

10. **Font loading** - Fonts are loaded in `app.tsx`; app won't render until ready
